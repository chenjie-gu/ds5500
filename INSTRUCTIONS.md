# Instructions

Step-by-step guide to set up and run the NSF CSE Funding Analysis.

## 1. Prerequisites

- **Python 3.9** (the project was developed and tested on 3.9)
- **Git** to clone the repository
- **Jupyter** (installed below) to run the notebook
- A package manager: **conda** (recommended) or **pip + venv**

## 2. Get the Code

```bash
git clone https://github.com/chenjie-gu/ds5500.git
cd ds5500
```

After cloning, confirm these files are present in the repo root:

- `NSF_Funding_Analysis.ipynb` — the analysis notebook
- `NSF_21_25_SG.xlsx` — the source data
- `NSF_Funding_Analysis_plots.pdf` — exported figures (regenerated by the notebook)

## 3. Create the Environment

### Option A — conda (recommended)

```bash
conda create -n ds5500 python=3.9
conda activate ds5500
pip install -r requirements.txt
```

### Option B — pip + venv

```bash
python3.9 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install --upgrade pip
pip install -r requirements.txt
```

Then install Jupyter (if it isn't already available):

```bash
pip install notebook
```

## 4. First-Run Setup (NLTK data)

The topic-modeling steps use NLTK stopwords/tokenizers. Download them once:

```bash
python -c "import nltk; nltk.download('stopwords'); nltk.download('punkt')"
```

## 5. Run the Notebook

```bash
jupyter notebook NSF_Funding_Analysis.ipynb
```

In Jupyter:

1. Make sure the kernel is set to the `ds5500` environment.
2. Run all cells top to bottom (**Cell → Run All**, or **Kernel → Restart & Run All**).
3. The notebook reads `NSF_21_25_SG.xlsx` from the repo root, regenerates every figure, and the final cell exports them to `NSF_Funding_Analysis_plots.pdf`.

## 6. Expected Output

- All charts and maps render inline in the notebook.
- `NSF_Funding_Analysis_plots.pdf` is (re)written in the repo root with the full set of figures.

## Troubleshooting

| Problem | Fix |
|---------|-----|
| `FileNotFoundError: NSF_21_25_SG.xlsx` | Run Jupyter from the repo root, or update the file path in the data-loading cell. |
| `ModuleNotFoundError` | Confirm the `ds5500` environment is active and rerun `pip install -r requirements.txt`. |
| Excel file won't read | Ensure `openpyxl` is installed (it's in `requirements.txt`). |
| PDF export fails / blank images | Ensure `kaleido` is installed; restart the kernel and run all cells again. |
| NLTK `LookupError` | Re-run the download command in Step 4. |
| Wrong kernel in Jupyter | `python -m ipykernel install --user --name ds5500`, then select it under **Kernel → Change kernel**. |

## Notes

- Runtime depends on your machine; the topic-modeling cells (LDA and BERTopic) are the slowest. Allow a few minutes for a full run.
- The first BERTopic run may download a sentence-embedding model, which requires an internet connection.
